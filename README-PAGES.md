# 固定ページ作成手順

## 1. 予約ページの作成

1. WordPress管理画面 → 「固定ページ」→「新規追加」
2. **タイトル**: `ご予約` (または `予約` / `Reserve`)
3. **パーマリンク(URL)**: `/reserve/`
4. 本文に以下のショートコードを貼り付け:
   ```
   [rentacar_booking]
   ```
5. 「公開」をクリック

### ページビルダーを使用している場合
- Elementor: 「ショートコード」ウィジェットを追加し、`[rentacar_booking]` を入力
- WPBakery: テキストブロックに `[rentacar_booking]` を入力
- その他: テキストモードで `[rentacar_booking]` を入力

## 2. キャンセルページの作成

1. WordPress管理画面 → 「固定ページ」→「新規追加」
2. **タイトル**: `予約キャンセル` (または `Cancel`)
3. **パーマリンク(URL)**: `/cancel/`
4. 本文に以下のショートコードを貼り付け:
   ```
   [rentacar_cancel]
   ```
5. 「公開」をクリック

## 3. キャンセルページIDの設定

1. 作成したキャンセルページの固定ページIDを確認
   - 固定ページ一覧で、キャンセルページにカーソルを合わせるとURLの `post=XX` に表示されるIDです
2. 「レンタカー予約」→「設定」画面で「キャンセルページID」を設定
   - ※これを設定することで、予約確認メールの {cancel_url} が正しいURLになります

## 4. メニューへの追加

1. 「外観」→「メニュー」
2. 「固定ページ」から「ご予約」を選択し「メニューに追加」
3. メニューを保存

## 5. 動作確認

1. 予約ページ (`/reserve/`) にアクセス
2. 車両が表示されることを確認
3. 予約フロー（6ステップ）を通しでテスト
4. キャンセルページ (`/cancel/`) にアクセス
5. 予約番号を入力してキャンセルフローをテスト

## URL構成例

| ページ | URL | ショートコード |
|--------|-----|---------------|
| 予約フォーム | `https://example.com/reserve/` | `[rentacar_booking]` |
| キャンセルフォーム | `https://example.com/cancel/` | `[rentacar_cancel]` |

## 注意事項

- 1ページにつき1つのショートコードのみ配置してください
- `[rentacar_booking]` と `[rentacar_cancel]` は別ページに配置してください
- パーマリンク設定は「投稿名」推奨（設定 → パーマリンク）
