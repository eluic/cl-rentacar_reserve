# デプロイ手順 — FileZilla + Xserver

## 前提条件
- Xserver上にWordPress 5.8以上がインストール済み
- PHP 7.4以上
- OpenSSL拡張が有効
- FileZillaがインストール済み

## 手順

### 1. FileZillaでサーバーに接続
1. FileZillaを起動
2. ホスト: `sv○○○○.xserver.jp` (Xserverのサーバー情報を確認)
3. ユーザー名・パスワード: Xserverのサーバーパネルで確認
4. ポート: 21 (FTP) または 22 (SFTP推奨)
5. 「クイック接続」をクリック

### 2. プラグインフォルダをアップロード
1. リモート側で以下のパスに移動:
   ```
   /home/[サーバーID]/[ドメイン名]/public_html/wp-content/plugins/
   ```
2. ローカル側で `rentacar-booking` フォルダを選択
3. フォルダごとリモート側にドラッグ＆ドロップ

### 3. パーミッション設定
FileZillaでアップロード後、以下のパーミッションを設定:

| 対象 | パーミッション |
|------|---------------|
| ディレクトリ（フォルダ） | 755 |
| ファイル（.php, .js, .css等） | 644 |

**設定方法:**
1. `rentacar-booking` フォルダを右クリック → 「ファイル属性」
2. 数値を `755` に設定
3. 「サブディレクトリに再帰的に適用」にチェック
4. 「ディレクトリのみに適用」を選択 → OK
5. 再度右クリック → 「ファイル属性」
6. 数値を `644` に設定
7. 「ファイルのみに適用」を選択 → OK

### 4. プラグインの有効化
1. WordPress管理画面にログイン
2. 「プラグイン」→「インストール済みプラグイン」
3. 「Rentacar Booking」の「有効化」をクリック
4. → 自動的にデータベーステーブル（13個）が作成されます

### 5. 初期設定
1. 左メニュー「レンタカー予約」→「設定」
2. 以下を設定:
   - **店舗名**: CLレンタカー
   - **電話番号**: 店舗の電話番号
   - **メールアドレス**: 通知先メールアドレス
   - **住所**: 店舗住所
   - **営業時間**: 例 08:00 〜 20:00
3. 「設定を保存」をクリック
4. 「メール送信テスト」でメールが届くか確認

### 6. 車両の登録
1. 「レンタカー予約」→「車両管理」
2. 「+ 車両を追加」をクリック
3. 車両情報を入力（名前、料金、定員、ミッション等）
4. WordPress メディアライブラリに画像をアップロードし、そのIDを設定

### 7. 固定ページの作成
→ `README-PAGES.md` を参照

## トラブルシューティング

### テーブルが作成されない
- プラグインを一度無効化 → 再有効化
- PHP 7.4以上であることを確認

### メールが届かない
- 「設定」→「メール送信テスト」でテスト
- Xserverの場合、`wp_mail()` は通常そのまま動作します
- SPF設定がサーバードメインと一致していることを確認

### 画像が表示されない
- WordPress メディアライブラリにアップロードし、そのIDを車両の「サムネイル画像ID」に設定してください
