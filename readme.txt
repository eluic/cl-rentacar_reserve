レンタカー予約システム — 車両管理・予約管理・決済・メール通知を一括管理するWordPressプラグイン。

== Description ==

沖縄のCLレンタカー向けに開発されたレンタカー予約管理プラグインです。

**主な機能:**
* 6ステップの予約フォーム（ショートコード [rentacar_booking]）
* 3ステップのキャンセルフォーム（ショートコード [rentacar_cancel]）
* 車両管理（画像・料金・在庫・定員・ミッション）
* 予約管理（ステータス管理・検索・フィルタ）
* 日別在庫管理（カレンダー・一括編集）
* 季節料金設定
* 追加オプション（カーナビ・ETC・チャイルドシート・免責補償等）
* 現地決済 / Square カード決済対応
* メールテンプレート（管理画面から編集可能）
* reCAPTCHA v3 スパム対策
* レート制限

== Installation ==

1. `rentacar-booking` フォルダを `/wp-content/plugins/` にアップロード
2. WordPress管理画面で「プラグイン」から「Rentacar Booking」を有効化
3. 「レンタカー予約」メニューから設定を行う
4. 固定ページに [rentacar_booking] と [rentacar_cancel] を配置
